\subsection{Implementation Details}
Our analysis framework is implemented in Python using PyTorch, scikit-learn, and SciPy. The complete codebase includes:
\begin{itemize}
    \item Unified clustering pipeline for trajectory extraction
    \item 17 transformation analysis modules
    \item Comprehensive test suite (175+ tests)
    \item Visualization tools for exploring transformations
    \item Documentation and tutorials
\end{itemize}

\subsection{Reproducibility}
All experiments can be reproduced using our provided code and configuration files. Key parameters:
\begin{itemize}
    \item Model: GPT-2 (124M parameters)
    \item Clustering: k=10 clusters per layer, unified approach
    \item Tokens: 1,000 diverse vocabulary samples
    \item Contexts: 9 linguistic frames (baseline + 8 context types)
    \item Random seeds: Fixed for reproducibility
\end{itemize}
